# What must be copied from the training host

This repository was assembled from a working tree that lives on the training server. A few files
there are private modules rather than clones, and they are **not** in `scripts/`. Copy them into
the paths below before running anything.

Assumed server layout: `/mnt/data/underwater/bpinn_uq/`

## 1. Required — the ported uncertainty modules

```
/ckpt/...                        -> (see section 2)
/code/uq/nig_layer.py            -> uq/nig_layer.py
/code/uq/normal_inverse_gamma.py -> uq/normal_inverse_gamma.py
/code/uq/der_loss.py             -> uq/der_loss.py
/code/uq/tu_risk_coverage.py     -> uq/tu_risk_coverage.py   (or generate it, see below)
```

`uq/tu_risk_coverage.py` is generated by `scripts/port_risk_coverage.py` — run that instead of
copying, if you prefer to regenerate the port from a clean TorchUncertainty checkout:

```bash
python scripts/port_risk_coverage.py   # writes uq/tu_risk_coverage.py
```

Every evaluation script imports these as `from uq.nig_layer import ...`, so the `uq/` package must
sit on `sys.path` (the scripts already insert the code root).

## 2. Required — the data split

```
/ckpt/funie_baseline/split.json -> ckpt/funie_baseline/split.json
```

This fixes the 500-image calibration / 500-image test partition of EUVP that every number in the
paper depends on. Without it, results will not reproduce.

## 3. Recommended — checkpoints

```
/ckpt/funie_baseline/best.pth            -> ckpt/funie_baseline/best.pth
/ckpt/funie_edl/best.pth                 -> ckpt/funie_edl/best.pth
/ckpt/funie_ensemble/seed_{0..4}/best.pth -> ckpt/funie_ensemble/seed_{0..4}/best.pth
/ckpt/ushape_*/...                       -> ckpt/ushape_*/
```

These are small (FUnIE-GAN is ~2M parameters; the five-member ensemble is roughly 10M in total) and
can live in a GitHub release or on Zenodo. They are gitignored by default.

## 4b. Required — the U-shape ensemble audit records

`records/` currently holds twenty audit JSONs. Two more were produced on the training host and were
never copied back, and Table VII's U-shape+ENS column rests entirely on them:

```
/outputs/ushape_ens_audit.json   -> records/ushape_ens_audit.json
/outputs/ushape_ens_reffree.json -> records/ushape_ens_reffree.json
```

Without them the U-shape+ENS cells of Table VII (marginal $1\sigma$ 27.6\% / 17.4\%, ratio
2.854$\to$3.755, AURC 0.0373$\to$0.0919) and its RUIE $\rho$ entry of $+0.14$ cannot be reproduced
from the released records. The other three columns of that table are covered by
`ushape_stratified.json`, `ushape_crossdomain_uieb.json` and `ushape_rejection_stage4.json`.

## 5. Optional — the raw per-pixel arrays

```
/outputs/arrays_EUVP.npz  (85 MB)
/outputs/arrays_UIEB.npz  (76 MB)
```

These hold the per-image $\sigma$ and error maps at native resolution. Too large for a repository
and better served from Zenodo; link the DOI in the README once minted.

## Sanity check

After copying, this should print two lines and no traceback:

```bash
python -c "import sys; sys.path.insert(0,'.'); from uq.nig_layer import NormalInverseGammaConvNd; print('nig_layer OK')"
python -c "import json; d=json.load(open('ckpt/funie_baseline/split.json')); print('split OK', len(d))"
```
